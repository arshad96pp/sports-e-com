# Hero photography

Drop these 8 files into this folder (`public/images/hero/`). The hero (`src/components/home/Hero.tsx`)
already references these exact paths — nothing else needs to change once they're added.

| File | Slide | Orientation | Recommended size |
|---|---|---|---|
| `football-desktop.jpg` | Football | Landscape (16:9) | ~2400×1350 |
| `football-mobile.jpg` | Football | Portrait (3:4) | ~1080×1440 |
| `cricket-desktop.jpg` | Cricket | Landscape (16:9) | ~2400×1350 |
| `cricket-mobile.jpg` | Cricket | Portrait (3:4) | ~1080×1440 |
| `tennis-desktop.jpg` | Tennis | Landscape (16:9) | ~2400×1350 |
| `tennis-mobile.jpg` | Tennis | Portrait (3:4) | ~1080×1440 |
| `accessories-desktop.jpg` | Sports Accessories | Landscape (16:9) | ~2400×1350 |
| `accessories-mobile.jpg` | Sports Accessories | Portrait (3:4) | ~1080×1440 |

Guidance for the shots (matches the copy already written into each slide):

- **Football** — a footballer in match gear on a pitch, dynamic action or gear-focused moment.
- **Cricket** — a cricketer with a bat, in stance, on a realistic ground.
- **Tennis** — a tennis player mid-swing on a premium court.
- **Sports Accessories** — a styled flat-lay/composition of bottle, gloves, cones, training gear and bags.

Keep the **left third of the desktop shots relatively uncluttered** (sky, turf, negative space) — that's
where the dark gradient sits and the headline/CTA are placed, so the subject should read clearly on the
right/center of the frame. For mobile crops, keep the subject centered-to-upper-frame with clear space
near the bottom for the text/CTA gradient.

Until these files exist, each slide falls back to a plain dark background (no broken-image UI).
